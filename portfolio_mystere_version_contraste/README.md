# Portfolio de Mystère Kongoli

Site statique responsive, sans dépendance de compilation.

## Prévisualisation

Ouvrir `index.html` dans un navigateur. Pour un serveur local : `python3 -m http.server 8000` puis ouvrir `http://localhost:8000`.

## Publication GitHub Pages

1. Créer un dépôt public nommé `portfolio` (ou `utilisateur.github.io`).
2. Importer les trois fichiers `index.html`, `style.css`, `script.js` à la racine.
3. Dans Settings > Pages, choisir « Deploy from a branch », `main`, `/ (root)`.
4. Attendre la publication ; l'URL sera affichée dans les paramètres Pages.
5. Ajouter cette URL à la section « Sélection » de LinkedIn et au CV.

## À personnaliser avant partage

- Remplacer le lien LinkedIn générique par l'URL du vrai profil.
- Ajouter une photo autorisée et des captures des projets quand elles sont disponibles.
- Vérifier les dates exactes et les descriptifs avec l'intéressé.
- Ajouter des preuves publiques des réalisations et s'assurer des droits de publication.
- Optionnel : configurer un domaine personnel (disponibilité à vérifier).

## Confidentialité

Ne pas publier de données personnelles sensibles, clés API, secrets d'infrastructure ou données non publiques d'utilisateurs.
